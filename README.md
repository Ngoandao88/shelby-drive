## 📌 Overview

**Shelby Drive** is a decentralized alternative to Google Drive, powered by Shelby Protocol's high-performance blob storage. Users can upload any file, set access permissions (public, private, or paid), and monetize their content — all without relying on centralized servers.

## ✨ Features

- 📤 **Upload any file** — PDFs, images, videos, ZIPs — stored as Shelby blobs
- 🔐 **3 access modes** — Public (free), Private (owner only), Paid (unlock with ShelbyUSD)
- 💰 **On-chain monetization** — earn ShelbyUSD when others download your files
- 🔄 **Auto-renewal** — blob renewal logic to keep files accessible beyond 48h testnet limit
- 📊 **Dashboard** — track downloads, earnings, and storage usage
- ⛓️ **Aptos smart contract** — access control and payments settled on-chain
